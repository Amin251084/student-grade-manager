# Student Grade Manager

A simple Python application for managing student grades and evaluating academic performance.

## Features

- Enter student name.
- Input grades for multiple subjects.
- Validate user input.
- Calculate average grade.
- Find the highest grade.
- Find the lowest grade.
- Determine academic status.
- Display average grade with two decimal places.
